# blindbet organization defaults

This repository contains default community health files, issue templates, and pull request templates for repositories in the `blindbet` GitHub organization.

Repositories can override these defaults by adding their own files in the same paths.

## Contents

- `CODE_OF_CONDUCT.md` - community standards and enforcement expectations.
- `CONTRIBUTING.md` - contribution workflow and review guidelines.
- `LICENSE` - proprietary license notice.
- `SECURITY.md` - private vulnerability reporting guidance.
- `SUPPORT.md` - where to ask questions and request help.
- `ISSUE_TEMPLATE/` - default issue forms for bugs and feature requests.
- `PULL_REQUEST_TEMPLATE.md` - default pull request checklist.
